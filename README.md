# BakeFlow – My Home Bakery

A responsive customer-facing bakery website prototype for My Home Bakery, Kakinada.

## Included
- 44 real cake photos supplied for the project
- Cake types and flavours from the bakery information provided
- Custom cake type and custom flavour inputs
- Bakery menu with illustrative website visuals where photos were not supplied
- Order buttons for cakes and all 14 bakery items
- Order form that works on mobile and laptop and opens WhatsApp with the entered order details
- Responsive dashboard and chatbot
- Chatbot answers only from the provided bakery data and says it does not know when information is unavailable
- `manifest.webmanifest` for installable/PWA-style support after hosting

## Open on laptop
1. Extract the ZIP.
2. Open the `BakeFlow` folder in VS Code.
3. Right-click `index.html`.
4. Choose **Open with Live Server** if Live Server is installed.
5. The website opens in your browser.

You can also double-click `index.html` to view the static site, but Live Server is better for testing.

## Open on mobile / any device
A local `index.html` file is not automatically a public website. To let others open it on their phones/laptops, upload the folder to a web host such as GitHub Pages, Netlify, or another static host. Then share the generated HTTPS link.

Before permanently publishing the hackathon prototype publicly, get the bakery's permission as required by the hackathon guide.

## Ordering
- Cake orders: choose Cake → cake type → flavour → size → date → delivery area → customization.
- If the required cake type/flavour is not listed, select **Other / Custom** and type it.
- Bakery item orders: choose Bakery Item → select item → quantity → date → delivery area.
- The final button opens WhatsApp to the bakery number supplied for the project.

## Important data note
Exact prices were not supplied, so the site does not invent prices. The bakery confirms final price and availability.
